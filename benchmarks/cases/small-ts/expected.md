# 評価用の期待事項：small-ts

このファイルは評価者向けであり、モデル作成時にはエージェントに渡さない。

## 対象と前提

- `input/task.ts` の `complete` を単一呼び出しとして扱う。型を満たす引数と通常の可変オブジェクト、並行した外部変更がない前提を置く場合は明記する。
- TypeScript の型宣言は実行時バリデーションではない。型外の値を分析対象外とすることは可能だが、その範囲と根拠を区別する。

## 必須の振る舞い

| 操作前 | 戻り値 | 操作後 |
|---|---|---|
| `task === null` | `false` | Task の変更はない |
| 非 null、`status === "doing"` | `true` | `status === "done"` |
| 非 null、`status === "todo"` または `"done"` | `false` | `status` は変更されない |

- 正常に `true` を返すとき、Task は `done`。非 null の Task に対して `false` が返るときは status が変わらない。
- `done` を再度完了させても `true` にはならない。`null` は短絡評価で `false` を返し、通常この関数の中では例外を発生させない。
- `undefined` や不正な実行時入力、frozen object、getter、Proxy などを含めるかは分析範囲に依存する。型宣言だけで、それらが実行時に不可能だと断言しない。

## 評価観点

入力と戻り値の三つのケースを区別し、状態の変更と不変条件を明示できるか。モデルは有限の TLC 設定で構文・不変条件を検査できるか。仕様上の提案や未検査の結果を、実装から確認された事実と混同していないか。
